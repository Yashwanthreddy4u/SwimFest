SwimFest — Spec Test Runner

Specification-first checks that interact with the live SwimFest website and compare observed results to expected behavior.

Expected behavior comes from the specification. The runner opens actual site routes in hidden browser frames, interacts with safe controls, and compares the observed result with the requirement. PASS on a UI-presence case confirms only that the specified surface is live; it does not prove its business behavior. Authenticated workflows, payments, real tournament data, and security/load requirements are BLOCKED when this browser has no approved test account, deterministic fixtures, or integration service. Mutating production data is not attempted.
